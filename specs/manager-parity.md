# Выравнивание manager-app под воркера: единый стиль и безопасность

Цель: manager-app выглядит и защищён так же, как воркер — одна палитра, одни шрифты, одинаковые компоненты, паритет по безопасности сессии и сети.

Готово, когда:

- manager-app использует те же токены (акцент #4f46e5, Geist/Geist Mono или явно принятое единое решение) — tokens.css воркера как источник истины
- Компоненты выровнены: useToast API как у воркера (success/error/warning/info + dismissAll), ErrorBoundary с деталями и 2 кнопками, CommandPalette той же структуры (без global_search — его нет в менеджере)
- Безопасность: rate limiting на unlock/setup-master (как auth.rs воркера), auto-lock по idle (уже есть частично — довести до паритета), auto-login/session-resume ЛИБО осознанно отклонено (пометить в спеке)
- `npm run build` + `npx eslint src` чистые; `cargo check` чистый по manager-app/src-tauri

Границы: только manager-app (manager-app/src, manager-app/src-tauri). Воркер НЕ меняем — он источник истины. Без изменения бизнес-логики менеджера (синк, чат, лицензии не трогаем). Cert pinning и HMAC-подпись запросов — НЕ входят (это кросс-фича обоих приложений, отдельно).

Не трогать: воркер src/, сервер cc-sync-server, только что сделанные анимации/автосинк в менеджере (они уже в manager.css — аккуратно мерджить токены, не снести).

Риски: (1) смена токенов визуально «сломает» привычный вид менеджера — принять как цель. (2) Geist шрифты self-hosted в воркере — нужно скопировать font-файлы в manager-app, иначе fallback. (3) rate limiting в Rust менеджера — добавить по образцу воркера, не ломая сигнатуры команд.
