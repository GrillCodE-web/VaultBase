ℹ️ How the update flow works
1. Build — run npm run tauri build on your Mac. Tauri generates .dmg + .dmg.tar.gz + .sig signature file.
2. Upload — drag the .dmg.tar.gz file here, paste the .sig contents, publish.
3. Distribute — the /update endpoint returns Tauri-compatible JSON. App checks on startup and auto-downloads if newer version found.
4. Keys — Tauri updater needs your pubkey set in tauri.conf.json. Generate with: npx tauri signer generate -w ~/.tauri/cc-manager.key
