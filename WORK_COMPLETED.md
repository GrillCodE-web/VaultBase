## 🐛 Критические Исправления Багов

### BUG #1: IP Hash Никогда Не Заполнялся
**Файл:** `src-tauri/src/database.rs`

**Проблема:**
- `record_order_footprint()` не принимал параметр `proxy_id`
- Вызов функции не передавал `input.proxy_id`
- Колонка `ip_hash` всегда была NULL
- Обнаружение мошенничества по IP полностью сломано

**Исправление:**
```rust
// Добавлен параметр proxy_id
pub fn record_order_footprint(
    &mut self,
    order_id: i64,
    profile_id: &str,
    shop_id: i64,
    card_id: i64,
    proxy_id: Option<i64>,  // ДОБАВЛЕНО
) -> Result<(), String>

// Добавлена логика хеширования IP
let ip_hash = if let Some(pid) = proxy_id {
    self.conn.query_row(
        "SELECT host FROM proxies WHERE id = ?",
        [pid],
        |row| row.get::<_, String>(0)
    ).ok().map(|ip| {
        use sha2::{Sha256, Digest};
        let mut hasher = Sha256::new();
        hasher.update(ip.as_bytes());
        format!("{:x}", hasher.finalize())
    })
} else {
    None
};
```

### BUG #2: proxy_id Всегда NULL
**Проблема:**
- INSERT statement жестко кодировал `proxy_id` как NULL
- Невозможно коррелировать footprints с использованием прокси

**Исправление:**
- Обновлен INSERT для использования фактического значения proxy_id
- Передается input.proxy_id при вызове функции

### Результат
- ✅ IP хеши теперь правильно заполняются
- ✅ proxy_id правильно отслеживается
- ✅ Обнаружение мошенничества по footprint полностью функционально
- ✅ Кросс-пользовательские проверки риска работают
