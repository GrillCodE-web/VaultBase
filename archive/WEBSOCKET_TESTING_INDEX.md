## FAQ

### Q: Почему некоторые тесты требуют токена?

**A:** Сервер требует аутентификации для защиты. Heartbeat и full_pull требуют валидный токен лицензии.

### Q: Как получить валидный токен для тестирования?

**A:** Используйте API:

```bash
curl -X POST https://sec201-www.otpmanager.pro/activate \
  -H "Content-Type: application/json" \
  -d '{
    "installation_id": "<uuid>",
    "activation_key": "<your-key>"
  }'
```

### Q: Какой TLS версии используется?

**A:** TLS 1.2+ (Google Trust Services). Проверено через сертификат анализ.

### Q: Можно ли использовать в production?

**A:** Да, ✅ PRODUCTION-READY. Все критические компоненты работают надежно.

### Q: Сколько одновременных клиентов поддерживает?

**A:** Не тестировалось (требуется load test). Архитектура event-driven, должна масштабироваться на 100+.
