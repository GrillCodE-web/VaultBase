# Редизайн: «Obsidian Terminal»

Дата: 2026-08-08

## Зачем

Прошлая «редизайн»-итерация свела 36 CSS-файлов в 5 и перевела всё на
`var()`-токены — это была **инфраструктура**, а не визуальная переработка.
Значения токенов при этом были выставлены под **клон macOS**: системный шрифт
`-apple-system`, systemBlue `#0a84ff`, плоские vibrancy-панели, мягкие
скругления. Отсюда ощущение «ничего не поменялось» — интерфейс выглядел как
любое нативное приложение, без собственного лица.

Диагностика подтвердила, что **никакие старые файлы не подтягиваются**: цепочка
импорта `main.jsx → src/index.css → styles/index.css → {fonts, tokens, base,
layout, components, pages}` корректна, дублей-конфликтов классов между файлами
нет (то, что выглядело дублями, — легитимные `@media`-переопределения). Проблема
была не в конфликте файлов, а в **отсутствии идентичности**.

## Что сделано

Поскольку всё построено на токенах, идентичность заданa в основном через
`tokens.css` и распространяется на все 20+ страниц разом.

### 1. Типографика — self-hosted шрифты

- Добавлены **Geist** (характерный гротеск от Vercel — не Inter, не системный) и
  **Geist Mono** (табличный моноширинный на все числовые поля: карты, суммы,
  трек-номера выравниваются по колонкам).
- Файлы `.woff2` лежат в `public/fonts/` (6 начертаний, ~40 КБ каждый),
  подключены через `src/styles/fonts.css` (`@font-face`, `font-display: swap`).
- CSP приложения (`tauri.conf.json`) дополнен `font-src 'self'` — без этого
  движок блокировал бы локальные шрифты.

### 2. Палитра — voltage cyan вместо systemBlue

- `--accent`: `#0093b8` (светлая) / `#00b3e6` (тёмная). Намеренно НЕ systemBlue —
  это подпись темы.
- Тёмная тема переведена на **графит** `--bg: #0c0d10` (почти-чёрный с холодным
  подтоном) вместо плоского серого `#1e1e1e`. Слои расходятся ступенями по
  светлоте, чтобы панели читались без тяжёлых теней.
- Значения синхронизированы во всех трёх тёмных ветках токенов
  (`[data-theme='dark']`, `[data-theme='system']`, `@media prefers-color-scheme`).
- `--color-chart-revenue` переведён на cyan; хардкод-стрелки `<select>`
  перекрашены из синего в нейтрально-серый (стрелка не должна быть акцентной).

### 3. Геометрия — резче, «аппаратно»

- Радиусы уменьшены (`--r-md: 6px → 4px` и т.д.): кнопки и поля почти
  прямоугольные, только чуть сняты углы — терминальный, а не «пузырьковый» вид.

### 4. Атмосфера фона (сигнатурная деталь)

- На тёмной теме `body::before/::after` добавляют тонкий радиальный cyan-подсвет
  сверху + едва заметную зернистость (инлайновый SVG-шум, `opacity ~0.03`,
  `pointer-events: none`). Почти-чёрный фон перестаёт быть мёртво-плоским.
  Только тёмная тема; контент поднят над слоями через `#root { z-index: 1 }`.

### 5. Компоненты

- **Таблицы**: заголовки колонок — микро-капс (`uppercase`, `letter-spacing`,
  Geist Mono) как «поля данных» ops-терминала. Выделенная строка — не сплошной
  флуд акцентом, а тонкий cyan-фон + левая метка `inset 2px 0 0 --accent`, чтобы
  моноширинные данные оставались читаемыми.
- **Сайдбар**: активный пункт — «канал» с яркой левой меткой и cyan-иконкой
  вместо сплошной заливки.
- **Кнопка основного действия**: при наведении — лёгкое cyan-свечение
  (`box-shadow` с `--accent-dim`), действие ощущается «живым».

### 6. Вёрстка страниц (общие примитивы, не по-страничная правка)

Все 11 контент-страниц используют общие классы `.content` / `.ph` / `.panel`,
поэтому правка примитивов меняет их разом.

- **Заголовки страниц** (`.ph-title`): перед текстом — вертикальный cyan-«тик»
  (`::before`, 3×18px). Страница читается как активный раздел терминала.
  Кегль выровнен (24→22px), разрядка убрана в минус — плотнее, аккуратнее.
- **Инлайн-алерты**: добавлен токенный компонент `.alert` +
  `.alert-error/-warning/-success/-info` (левая цветная кромка, фон из
  семантических токенов). Заменил в `Cards.jsx` баннер на сырой Tailwind-палитре
  (`bg-red-900/20 border-red-800 text-red-400`) — единственное место в
  страницах, где цвета шли мимо темы и выглядели инородно. Теперь у ошибок
  синхронизации единый вид, и класс переиспользуем.
- **Панели** (`.panel`): верхняя cyan-кромка (`::before`) переведена из сплошной
  полосы в градиент, затухающий к краям (`opacity 0.25`) — аккуратная подсветка
  контейнера таблицы, а не линия-артефакт над заголовками.

Проверено: сырых Tailwind-палитр (`bg-*-900`, `text-red-400`) в страницах не
осталось (`bg-green-400` в `Login.jsx` — это метка индикатора силы пароля, а не
поверхность, оставлена осознанно).

## Проверка

- `vite build` — зелёный; `vitest` — **317/317**.
- Идентичность подтверждена в **скомпилированном** CSS (`dist/assets/index-*.css`),
  а не только в исходниках: `--accent: #0093b8/#00b3e6`, `--bg: #0c0d10`,
  `font-family: Geist`, `uppercase` в заголовках таблиц, ноль systemBlue-стрелок.
- Браузерный предпросмотр в этой сессии был недоступен: экран входа вызывает
  Tauri-команду `is_password_set`, которая без бэкенда не резолвится, и React
  зависает на спиннере. Поэтому верификация — программная (замер значений в
  собранном CSS + тесты), а не по скриншоту.

## Остаётся

Увидеть вживую можно только в собранном приложении (десктоп-бэкенд нужен, чтобы
пройти мастер-пароль). Светлая тема сохранена и переведена на ту же cyan-подпись;
тёмная — hero-режим.
