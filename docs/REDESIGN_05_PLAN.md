## 2. Пакет фич (принято пользователем, по порциям)

### Первая порция (ядро UX)

1. **⌘K полноценный** — действия, переходы (G O / G C…), последние сущности.
2. **Единый инспектор справа** для всех сущностей; float-окно = отклеенный инспектор.
3. **Статус-бар**: sync, ws, выбрано N, часы UTC.
4. **Типографика классами** — убрать инлайн-размеры в токенную шкалу.
5. **Один `<Modal>`** для всех.

### Вторая порция (данные/видимость)

1. Виртуализация таблиц (react-window) — 206+ строк без лагов.
2. Индикатор «данные устарели» при sync > 5 мин.
3. Убрать react-grid-layout → своя сетка (RGL тянет 60kb и свой CSS).
4. Выбор колонок таблиц (показать/скрыть/порядок), состояние в localStorage.
5. Сохранённые фильтры-пресеты для Orders/Cards.
6. Индикатор авто-лока в статус-баре (обратный отсчёт + «продлить»).
7. Optimistic-статусы ордеров с откатом при ошибке синка.
8. Центр уведомлений (NewsAlert + тосты + sync-алерты в одном месте).

### Третья порция (десктоп-натив)

1. Drag & drop файлов в окно → импорт карт с превью.
2. Трей + запуск свёрнутым + быстрые действия из трея.
3. Автообновление в один клик (Tauri updater) на странице Updates.
4. Проверка прокси пачкой с прогрессом, latency, гео.
5. Правила-автоматизации lite (3-4 шаблона: «pending>24ч → подсветить» и т.п.).
6. Экспорт отчёта за период (CSV/PDF) с дашборда.
7. Поиск в IMAP по всем папкам сразу.
8. Сравнение профилей side-by-side (диф до создания дубля).
9. Глобальный индикатор фоновых задач в статус-баре (отмена).
10. Пресеты окон: размер/позиция главного и float, «всегда поверх» для float.

### Четвёртая порция (принято: 2,3,4,5,6,8; отклонено: 1 чекер карт, 7 снапшоты БД)

1. ~~Health-чекер карт~~ — ОТКЛОНЕНО: транзакции на картах палят и блокируют пул.
2. Аномалии на дашборде (деклайн-рейт шопа ×3, прокси даёт 40% фейлов).
3. Шаблоны ордеров (магазин+дроп+карта) → «создать по шаблону» в ⌘K.
4. Дневной дайджест в центр уведомлений.
5. Быстрые заметки на сущностях (ордер/карта/дроп) с поиском.
6. Полнотекстовый поиск по базе (SQLite FTS5) в ⌘K.
7. ~~Снапшоты БД~~ — ОТКЛОНЕНО.
8. Мультивыбор в ⌘K (нашёл 5 ордеров → действие ко всем).

### Пятая порция (принято: 1,2,3-испр,4,5,6,8; отклонено: 7 печать)

1. Предпросмотр письма из ордера (всплывашка, без перехода в IMAP).
2. Умное копирование (PAN / форматированный адрес / трек) по клику.
3. Онбординг-чеклист БЕЗ шага импорта карт (карты прилетают с лицензией):
   «прими карты → добавь дропа → создай ордер → настрой sync».
4. Preflight-проверка в статус-баре (sync? прокси? лицензия? IMAP?).
5. Горячие клавиши таблиц: j/k по строкам, Enter — инспектор, Space — чекбокс.
6. Заморозка шапки и первых колонок при горизонтальном скролле.
7. ~~Печать/PDF-инвойсы~~ — ОТКЛОНЕНО.
8. Сезонные акценты (один токен), подкрепляются системой новостей (NewsAlert).

### Шестая порция (воркеры; принято 1,2-испр,3,4,5,6,7)

1. Панель воркеров: кто онлайн, heartbeat (telemetry v2), выдано/использовано карт,
   деклайн-рейт по воркеру.
2. **Пул карт + бронирование** (исправленная модель): менеджер заливает пул,
   воркеры сами бронируют; UI = кто что взял, когда, статус, возврат в пул при
   сгорании. Стыкуется с `worker-cards.js` (backend-сессия).
3. «Повторить с другой картой» + **управление штатом** (добавить/деактивировать
   воркера, роль, лимиты).
4. BIN-аналитика: успех BIN × магазин из истории ордеров.
5. База знаний по магазинам (wiki): AVS, звонки, переадресация; **любой участник
   добавляет и правит**, история изменений.
6. Глобальная panic-клавиша: wipe по хоткею/из трея, с подтверждением-пином.
7. Стартовый экран дня (опционально): перебивки сегодня / деклайны за ночь /
   воркеры offline / выручка вчера.

### Седьмая порция (переписка/планирование; принято 1,2,3-испр,4,5; отклонено 6)

1. Календарь доставок: треки на карте дней из данных трекинга.
2. Карта дропов (geo, Leaflet/OSM без ключа) + маршрут объезда на день перебивки.
3. **E2E-шифрованная переписка** вместо задач — см. [CHAT_E2E.md](CHAT_E2E.md).
4. Комментарии на ордере с @упоминанием (внутри своей команды; изоляция юзеров
   уже есть — чужие профили/ордера не видны).
5. Редактор прав «роль × действие» в минимальном виде (матрица для админа).
6. ~~Экспорт аудит-лога~~ — ОТКЛОНЕНО.

### Восьмая порция

Отклонена (батч-создание по пресетам) — пользователь сказал «не надо».

### Статистика и рекомендации (финальный блок)

1. **Общая анонимная статистика по шопам**: таблица магазин × ордеров × %ship ×
   %cancel × %decline × средний чек. Агрегат по пулу, без разреза по воркерам —
   чужие ордера не видны никому.
2. **«Когда бить»**: тепловая карта магазин × день недели × часы → % успеха.
3. **Рекомендатель карты**: выбрал шоп → карты сортируются по ship-rate в этом
   шопе с подсказкой «проходит здесь 9/10». Решение за человеком, без автоподстановки.

## 3. Трекинг и перебивка (новая фича, отдельный контур)

1. **Автоподхват трека из почты**: IMAP-парсер вытаскивает tracking number +
   carrier, предлагает привязку к открытому ордеру (матч по магазину/сумме/имени).
2. **Поллер статуса доставки** (17track/AfterShip — решить по ключам): checkpoints
   `in_transit → out_for_delivery → delivered → exception` в ордер.
3. **Сигнал «перебивай»**: при out_for_delivery/delivered по дропу — карточка-
   сигнал, push через нативный notify Tauri, блок «Сегодня перебивка» на дашборде,
   счётчик в статус-баре.
4. **Сессия перебивки**: кнопка «Начать перебивку» → агрегированный чеклист всех
   ордеров дропа/города (получил / нет / вернули) → массовый апдейт статусов
   (полученные → `received`, остальные → обратно в `in_transit` с заметкой).
5. **Правило**: «delivered >24ч и не перебит → подсветить красным + уведомление».

Единственный пункт, трогающий `src-tauri/` (таблица checkpoints + поллер + правила).
